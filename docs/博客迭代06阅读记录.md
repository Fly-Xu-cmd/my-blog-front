# 第六轮：浏览器阅读记录

文章与笔记标题下可添加稍后再读；记录阅读进度和最近的标题锚点，下次进入由读者点击“继续上次阅读”，不自动跳转。保存位置每秒最多一次，页面隐藏或离开时补写。锚点仍存在时优先按锚点继续，正文改动导致锚点失效则用相对进度兜底。

/reading展示最近阅读与稍后再读，并可移出或确认后清空。仅当前浏览器，保存资源类型/ID、位置和时间，不保存token、正文、邮箱或文章标题；最大30条最近记录及50条稍后再读，合计最多80条。浏览器禁用存储或配额不足明确提示，不能假装保存成功。

展示清单前向只读POST /api/reading-library提交最多100个资源引用，服务端通过主键与published重新过滤并仅返回摘要。已隐藏、删除的条目不展示；读失败保留本地数据。接口无数据库写操作、no-store，不向其他设备同步。

默认正文继续服务端渲染，禁用JS时提示本地清单需要JS；阅读正文不受影响。按钮、筛选和确认使用AntD，ThemeProvider增加无额外布局节点的App上下文供消息/弹窗使用。
