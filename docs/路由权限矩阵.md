# 路由权限矩阵

管理写操作统一在解析正文、AI、图床及写库之前验证管理员 JWT；同步凭据不能代替管理员 JWT。未支持的方法由框架返回 405。

| 路由                                                     | 方法                     | 身份/可见性                                              |
| -------------------------------------------------------- | ------------------------ | -------------------------------------------------------- |
| /api/posts、/api/notes、/api/dynamics                    | GET                      | 默认仅公开；scope=admin 验证管理员                       |
| /api/posts、/api/notes                                   | POST                     | 管理员 + UUID Idempotency-Key                            |
| /api/dynamics                                            | POST、PUT、PATCH、DELETE | 管理员                                                   |
| /api/posts/[slug]、/api/notes/[slug]、/api/dynamics/[id] | GET                      | 默认仅公开详情；管理 scope 验证管理员                    |
| 上述详情                                                 | PUT、DELETE              | 管理员；笔记仅发布状态/类型，正文由同步维护              |
| /api/categories、/api/tags                               | GET                      | 默认仅公开内容使用的分类/标签；管理 scope 验证管理员     |
| /api/categories、/api/tags                               | POST、PUT、DELETE        | 管理员                                                   |
| /api/series                                              | GET                      | 默认仅含公开文章的系列；管理 scope 验证管理员            |
| /api/series                                              | POST、PUT、DELETE        | 管理员                                                   |
| /api/series/[id]/reorder                                 | POST                     | 管理员；完整排序，事务与占号约束                         |
| /api/upload、/api/upload-qiniu                           | POST                     | 管理员；实际图片签名/MIME/扩展名一致，最大 5MB，拒绝 SVG |
| /api/notes/sync、/api/notes/delete                       | POST                     | 独立 SYNC_API_TOKEN                                      |
| /api/notes/meta                                          | GET                      | 独立 SYNC_API_TOKEN；no-store                            |
| /api/auth/me                                             | GET                      | Authorization header 管理员 JWT                          |
| /api/about                                               | GET                      | 公开文案；scope=admin 验证管理员并返回版本与更新时间     |
| /api/about                                               | PUT                      | 管理员；版本校验；no-store                              |
| /api/reading-library                                     | POST                     | 匿名只读引用查询；仅公开文章/笔记摘要；最多100项；no-store |
| /api/login                                               | POST                     | 公开登录，仅服务器配置凭据验证                           |
| /api/login/[token]                                       | POST                     | 停用后 410                                               |
| /api/loginout                                            | POST                     | 无服务端状态的退出，不操作内容                           |
| /api/admin/content-stats、/api/analytics/stats           | GET                      | 管理员；no-store                                         |
| /api/analytics/site、/api/analytics/views                | GET                      | 公开累计缓存                                             |
| /api/analytics/heartbeat、/api/analytics/track           | POST                     | 匿名访客 ID 校验、Redis 原子限流                         |
| 页面、metadata、JSON-LD、RSS、sitemap、归档、标签/系列页 | GET                      | 仅公开内容；草稿详情 404                                 |

401 清理登录状态；403 提示权限错误。写操作不自动重试。管理请求和草稿预览 no-store。异常响应不包含原始 SQL、凭据或内部堆栈。
