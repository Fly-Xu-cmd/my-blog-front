# 第五轮：统一搜索

新增/search和/api/search，统一查询公开文章、技术笔记与随笔；按首次发布时间、资源类型与ID稳定排序，合并总数后统一分页。类型支持全部/文章/技术笔记/随笔，q最多100字符，分页沿用current/pageSize，最大50。%和_按普通字符查找，不扩展为通配符；SQL参数绑定。

数据库仅返回匹配正文附近最多240字符，经纯文本摘要处理后响应最多200字符，不把正文发送给客户端。关键词按React文本节点与mark显示，不能执行HTML。公开条件先于搜索；scope=admin需JWT，但统一搜索仍仅查公开内容。数据故障503、非法参数400，响应no-store。

首屏服务端渲染，禁用JS仍可读取直接链接的结果。后续搜索使用独立API读取、AbortController取消旧请求并忽略迟到回复；输入不因路由切换重建，快速连续输入的后一次查询生效。URL同步查询并支持前进/后退。AntD Input.Search、Segmented与Pagination共享主题，不添加页面底色。

单次查询使用RepeatableRead保持总数/页数据一致，查询提示上限3秒、事务10秒。当前内容规模采用字面子串查询；全文索引或外部搜索服务留待实际数据量需要时再做。

验收：隔离数据库定向2项、Linux Node24全套42项、typecheck/lint/build和standalone迁出源码smoke通过；Chromium21项通过、2项后台配对用例未运行（本轮无后台改动）。新增统一类型、字面特殊字符、公开过滤、组合分页、片段长度、无JS首屏、移动端和连续快速搜索回归。

独立评审发现请求失败清空旧结果，已改为仅成功后替换数据；失败提示与旧列表并列，旧列表使用上一成功查询的高亮和页码。增加503后旧结果可读、浏览器前进/后退恢复查询及快速输入等待最终结果回归；完整Linux验证及Chromium重验通过。一次新增测试定位碰到Next页面提示节点，已收窄为搜索区错误提示，产品逻辑未因此改动。

初次浏览器测试有宽关键词第一页包含大量其他合法结果的断言错误，以及路由重建导致快速第二次提交丢失；修正测试关键词与输入生命周期后全套重验通过。正式发布与大规模数据性能未验收。
