## 后台维护

前台/API 发布成功后，在后台“管理 → 关于页设置”（/manage/about）修改页面标题、一句话介绍及 Markdown 正文。正文右侧实时预览，点击“保存并更新前台”后公开生效，无需重新构建。头像继续使用原有头像。

一句话介绍同时用于搜索引擎 description，页面标题也同步进入 metadata。前台服务端读取最新配置，禁用 JavaScript 仍可阅读正文。原始 HTML 与危险协议链接不执行，预览使用现有安全 Markdown 编辑器。

配置保存到 AboutPage 固定 id=1。数据库没有配置行时使用上述首稿；首次保存才创建，不自动覆盖已有配置。读取失败会禁止保存；保存失败保留输入。两个窗口同时修改时，以 revision 校验拒绝旧版本，提示复制需要保留的内容后重新载入。离开或重新载入有未保存内容的页面会提示确认。

## 接口与发布

GET /api/about 返回公开文案；GET /api/about?scope=admin 验证管理员 JWT，另返回 revision 和 updatedAt；PUT /api/about 必须管理员 JWT，完整提交 title、subtitle、content 和载入时的 revision。成功版本加一，过期版本返回 409 ABOUT_VERSION_CONFLICT，数据库故障返回 503。接口均 no-store，写操作不自动重试。

标题最多 80 字符，简介最多 240 字符，正文最多 100000 字符，均不能为空。正文保留 Markdown 空白；版本必须非负整数。新迁移只增加表，不修改历史内容。部署先合入并发布前台/API，确认 readiness 包含 about-page-v1 后再发布后台；后台兼容检查会拒绝未支持此能力的 API。

正式发布时本次新增迁移仍需通过现有备份恢复检查。回退应用时保留新增表及配置；回退后台只移除编辑入口。生产数据及正式文案发布本轮未执行。
