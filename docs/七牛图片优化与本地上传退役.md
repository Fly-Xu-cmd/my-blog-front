## 图片展示

公开七牛域名 image.xylxf.xyz 的无查询参数图片通过 imageView2/2 按宽度缩放，质量 80、WebP；列表缩略图候选 100/160/240/320px，主推封面与正文 480/768/1200/1600px，尺寸上限 1920。浏览器根据 sizes 与 DPR 选择，直接请求七牛，服务器不负责生成缩略图。正文/列表默认懒加载、异步解码，服务端仍输出 img、srcset、替代文本。

签名 URL、已带处理参数、GIF/SVG、其他域名和本地静态资源保留原地址，不新增处理参数。处理失败时只回退一次原图，避免重试循环。图片内容更新使用新的七牛对象 key，不覆盖长缓存对象。

公开只读样本验证：8e1749f7-fb5e-4621-8e46-56ae21464131.jpg 原图 403631 字节，320px WebP 6476 字节，约为原图的 1.6%；处理 URL 返回 image/webp 和 public,max-age=31536000。此为单样本，不代表全站首屏、CPU 或所有图片类型性能。

## 本地上传退役

POST /api/upload 在鉴权后返回 410 LOCAL_UPLOAD_RETIRED，不解析文件、不访问磁盘。部署 workflow、prepare-release-directory、deploy-release 解除旧上传目录参数依赖；新 PM2 配置移除 UPLOAD_DIR，旧应用回退配置保留其原环境。

不删除旧文件或 Nginx 映射。正式退役目录前，运行只读引用审计，包含已发布及私有文章/笔记/动态和关于页正文、摘要、封面。报告只包含资源 ID、字段、旧路径，不输出正文、标题或查询参数凭据。

```sh
# 使用专门只读数据库连接；不要将密码写入命令历史。
pnpm exec tsx scripts/audit-image-references.ts --output=image-reference-audit.json
# 或在已配置 DATABASE_URL 的受控应用环境显式选择：
pnpm exec tsx scripts/audit-image-references.ts --configured --output=image-reference-audit.json
```

命令在本地或隔离验收环境执行，通过受限只读连接审计；正式服务器不运行 pnpm/tsx，也不安装应用开发依赖。默认使用 AUDIT_DATABASE_URL；--configured 才允许使用应用 DATABASE_URL。审计采用一个数据库连接的只读快照事务，每批10行，查询5秒上限、整体180秒上限、每表最多10000行；独立 CLI 在连接前设置进程级截止，握手/半关闭挂起也会终止该审计进程。AUDIT_TIMEOUT_MS 可缩短到1000ms，不能超过180000ms。超限/故障退出非零，不生成可用于清理的成功报告。旧成功报告须核对生成时间，不能将失败退出视为本次审计成功。

只有报告 complete=true、references 为空，并核对上一成功应用、Nginx/外部链接和备份后，才能决定正式目录清理。本轮提供可审核的代码和审计工具，未连接正式库、未删除正式目录。
