# 第七轮：私有反馈、讨论与分享

已确认私有反馈为主，另留GitHub讨论链接。文章/笔记正文末尾使用紧凑交流栏，AntD Modal提交纠错、疑问或建议；无需登录，邮箱选填。内容仅管理员后台读取，未发布内容不能接收新反馈，不公开评论或联系信息。

Feedback新增UUID提交标识和规范化请求hash。并发或响应丢失后同请求重试只写一条，同键不同内容409；后台状态为待处理/已处理/已忽略，不自动删除历史，不自动发邮件。管理GET/PATCH与配置PUT均先JWT，no-store；私有正文以React纯文本显示。

公开POST只接受JSON，流式读取最多8KB，正文最多2000字符，邮箱校验；校验来源、honeypot与Redis原子限流（默认每可信来源IP10分钟5次，FEEDBACK_RATE_LIMIT可配置）。仅TRUST_PROXY=true时信任部署代理x-real-ip，不信任时共用保守桶；Redis失败503、限流429及Retry-After，不降级成无限数据库写入。数据库不保存IP，Redis散列计数键600秒过期。

仓库Discussions未开启、Issues已开启，所以默认链接到现有Issues。后台可改成合法GitHub Issues/Discussions HTTPS链接或清空隐藏；不擅自改变GitHub仓库功能。配置保存有revision并发保护。

复制链接按当前浏览器origin生成。分享卡片在读者浏览器用Canvas生成1200×630 PNG，带标题、文章链接、可用封面；封面超时/跨域不可用仍可生成文字卡片，正式2核/2GB服务器无需渲染图片或安装新依赖。

主题订阅评估：保持现有全站RSS，暂不增加重复的按标签/系列feed。先观察主题阅读量和实际订阅需求；需要时沿用公开过滤，加入稳定分类/标签标识、订阅范围说明和独立验收，本轮不改订阅口径。

API及Feedback/FeedbackSettings兼容迁移先部署，后台要求feedback-v1。正式迁移前仍需已验证备份恢复；回滚保留反馈与配置表，回退兼容应用，不回退私有反馈鉴权。

隔离MySQL/Redis定向4项通过；Linux Node24全套44项、typecheck/lint/build、standalone迁出源码smoke通过。配对Chromium23项全部通过，覆盖响应丢失后同键重试只创建一次、匿名不能读私有反馈、脚本纯文本、后台状态更新与配置读取失败禁保存、GitHub链接、1200×630 PNG下载和移动端。后台22项Jest、tsc、biome lint、静态构建、部署兼容/Basic Auth探活6项通过。

联测初次点击AntD隐藏输入而超时，及处理后误匹配旧测试记录的断言问题，已改为点击可见Select和按本次唯一内容定位；只在验证隔离Redis端口后重置本次测试计数桶，重复验收不受历史运行影响。修正后全套Chromium通过。正式库/发布/真实邮箱联系和七牛实际CORS未验收。
