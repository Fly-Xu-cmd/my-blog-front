# 第四轮：可维护的首页阅读入口

后台选择一篇主推文章、最多三篇入门文章、最多三个推荐系列。文章支持服务端搜索，使用AntD Select；选择顺序为展示顺序，清空可隐藏对应块。首页沿用现有封面与透明页面，入门文章和系列用紧凑列排，不增加页面底色。

新增ReadingEntry JSON表与兼容迁移，CAS revision保护并发保存；省略字段保留当前值。保存验证内容存在且已公开，系列必须至少有公开文章。展示时重新查询公开条件，因此后来隐藏、删除的文章和空系列不会展示。推荐只返回摘要，绝不通过选择绕过草稿权限。配置读取失败不阻断下方首页数据。

GET /api/reading-entry公开读取返回已公开的展示数据；scope=admin先JWT再读取配置和已选条目。PUT先JWT，参数非法400、版本冲突409、依赖故障503，均no-store。后台读取失败不能保存，保存失败保留选择，上传无新增；离开保护复用第二轮同一WritingGuard。
