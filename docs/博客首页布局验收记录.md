# 博客首页布局验收记录

日期：2026-11-17。分支 `codex/blog-editorial-layout`，基于阶段 4 前台 `3403780`。本次仅改前台展示与测试夹具，没有修改后台、数据库结构或正式内容。

## 布局与封面

- 首页改为介绍、最近文章、笔记和动态分区，各数据块独立处理失败。
- 博客默认第一页突出首篇，其余文章使用横向列表；搜索、筛选及后续分页全部使用普通列表。
- 首篇有封面时右侧展示大图，手机上移到文字下方；后续有封面的文章在右侧展示缩略图。无封面不生成占位图。首页、博客和标签页复用同一文章组件。
- 笔记为紧凑目录，支持全部、技术笔记和生活随笔切换；动态按上海日期的月份组织时间线。
- 保留现有 URL、摘要列表契约、公开可见性、搜索、分类标签筛选、分页、主题、键盘焦点和减少动画偏好。
- 搜索、分类和标签选择、筛选弹层、笔记类型切换、清除/重试按钮及分页统一使用已有 Ant Design；主题切换、导航按钮、联系方式二维码也使用组件库。主题配色和中文 locale 统一配置，不新增组件库依赖。
- 首页、博客、笔记、动态和标签列表容器保持透明；关于页去掉覆盖整段介绍的大卡片底色。全局星空、流星和光晕可以透过内容区域显示，局部弹层仍使用组件库主题表面保证可读性。
