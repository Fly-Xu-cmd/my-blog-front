## 验收口径

自动化：各轮运行适用的 Vitest/Jest、类型检查、lint 和构建；前台在 Linux Node24 将 standalone 包迁出源码，验证 SSR、静态资源、公开接口、RSS、readiness 与迁移 CLI。独立评审为源码只读评审，不能称作评审者亲自完成服务或生产验收。

隔离联测：仅 tests/compose.yaml 对应的本机 MySQL 13316/blog_test、Redis 16386；配对后台静态包与前台 API 用 Chromium 验证。第五/六轮无后台改动，独立验收中对应的两个后台用例未运行；整合验收补全。正式数据库、正式 SSH、七牛实际跨域配置、正式发布与备份恢复均未验收。

## 跨轮合并规则

整合代码位于独立 integration worktree，用于提前验证共存及保存冲突解决依据，不修改主 checkout，不替代每轮 main PR。数据库模型必须保留 PostRevision、SiteSettings、ReadingEntry、Feedback、FeedbackSettings；新增迁移全部保留，不能改已应用迁移。

readiness 和后台能力检查保留并集：post-revisions-v1、site-settings-v1、reading-entry-v1、feedback-v1 以及原有能力。首页同时接收站点配置和阅读入口；导航同时保留搜索与我的阅读；正文同时保留阅读记录与交流分享；ThemeProvider 的 AntD App 上下文只包装一次；WritingGuard 和审计帮助函数保留共同实现。

整合自动化：后台29项Jest、tsc、biome lint、部署兼容/Basic Auth探活6项及所有管理页面静态构建通过；后台lint有3条非阻断告警。前台70项Vitest、类型检查、lint、构建及迁出源码的standalone探活通过；配对Chromium完整38项通过，覆盖七轮功能共存。
