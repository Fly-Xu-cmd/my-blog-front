# 项目诊断与优化建议

修订日期：2026-11-16。此版依据源码评审和已批准实施计划，取代初稿中未经本次复核的线上数量、分类重建、作品集及统计明细清理建议。历史分析见《项目诊断与优化建议-评审意见.md》。

## 已确认结论

| 问题                                              | 本轮优化                                                             | 状态                        |
| ------------------------------------------------- | -------------------------------------------------------------------- | --------------------------- |
| 管理写权限未覆盖、草稿读取泄露                    | 逐方法 JWT 防护、默认公开查询、管理 scope、详情/metadata/收录隔离    | 已实现，隔离验收            |
| 同步默认公开、slug 身份覆盖、相同 hash 忽略元数据 | 默认私有，以 syncId 识别，URL 不变，元数据独立比较                   | 已实现，正式旧内容待审      |
| JSON-LD 和原始 HTML 风险、上传绕过凭据            | 安全 JSON 序列化、禁原始 HTML、统一 token 上传、类型与大小检查       | 已实现，浏览器/隔离验收     |
| 创建失败重试重复、slug 前缀扫描/误重试            | 持久化幂等、唯一键定名、五候选、准备与事务重试分离                   | 已实现，真实 MySQL 并发验收 |
| 正文首屏和列表数据不足/过大                       | 服务端可读正文、稳定中文锚点、分页搜索、摘要和详情分离               | 已实现                      |
| 发布时序和内容模型欠缺                            | 首次发布时间、动态草稿、系列事务/约束、笔记类型                      | 已实现，历史迁移隔离核对    |
| 统计高频全库回源、范围不一致                      | 60 秒缓存、单次回源、原子限流、统一自然日范围                        | 已实现，保留累计和历史明细  |
| 阅读入口与工程维护                                | RSS、归档、标签/系列、进度/目录/相关文章、Node 24 CI、清理无引用源码 | 已实现，正式部署待阶段验收  |

## 不实施的方向

保持综合技术与随笔定位，不批量重建分类、不批量隐藏非技术内容、不合并 Post/Note、不重写旧 URL、不切换全库外键模式、不新增作品集、不实施统计归档或明细删除。累计 UV 使用全历史 visitorId 去重，不能累加日 UV。

## 发布前核查

正式隐私清单按用户确认留到发布前，由只读脚本输出，在后台逐项审查。正式备份和恢复、真实七牛上传、代理来源 IP 信任边界仍需发布环境核验。生产迁移和部署尚未执行，不把隔离环境通过等同于生产验收。

执行细则见《博客优化实施计划.md》，路由覆盖见《路由权限矩阵.md》，检查证据见《博客优化验收记录.md》。
